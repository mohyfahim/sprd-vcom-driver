# Security policy

This project accepts security reports for unsafe USB interface matching,
kernel crashes, memory corruption, privilege-boundary issues, and installer
path or permission vulnerabilities.

Do not open a public issue for an undisclosed vulnerability. Use GitHub's
private security-advisory feature for `mohyfahim/sprd-vcom-driver`, or contact
`fahimohy@gmail.com`. Include the affected version, reproduction steps, impact,
and any proposed fix. Do not include subscriber secrets or personal modem data.

Only the latest tagged release is guaranteed to receive security fixes. Kernel
issues accepted upstream will follow the Linux kernel security process.
